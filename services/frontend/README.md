# Arles Migrator UI

Paste an Arles gallery URL (default) or upload an exported album folder, preview and edit it, then publish to Google Photos.

How to run this — Google sign-in, Docker preview, local publish, album folders, and what Photos receives — is in the [root README](../../README.md).

## Run the UI locally

Start the API first (see the root README). Then from this folder:

```bash
npm install
npm run dev
```

Open [http://localhost:5173](http://localhost:5173).
